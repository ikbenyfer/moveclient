What's inside

18 modules across 3 categories

Every module starts disabled, toggles from the ClickGUI or a bindable key, and persists its settings to a JSON config file.

Movement — 11

Bhop

Auto-hop + Quake-style air-strafe acceleration.

Flight

Toggleable 3D flight with independent ascend/descend speed.

Speed

Ground movement multiplier via a reversible attribute modifier.

Step

Walk up full blocks without jumping.

HighJump

Jump height multiplier via the vanilla jump-strength attribute.

Gravity

Scales fall acceleration — floaty or heavy, independent of Flight.

AutoSprint

Sprints automatically while moving forward.

Spider

Climb any wall you're pressed against by holding jump.

AirJump

Extra mid-air jumps, edge-detected off the real key event.

NoClip

Disables world collision for testing level geometry.

ElytraBoost

Forward thrust while gliding, capped to a max speed.

Player — 6

Anti-Knockback

Cancels external velocity on both axes via a self-predicted baseline.

NoFall

Prevents fall damage; resets server-side fall distance once per landing.

Jesus

Walk on water; hold sneak to dive normally.

AutoTotem

Swaps a totem from anywhere in your inventory into offhand at low HP.

Criticals

Times a tiny hop so your own attacks land as critical hits.

Killaura

Auto-attacks the nearest hostile mob — players are hard-excluded in code.

World — 1

Xray

Lists nearby valuable ores through walls, with direction and distance.

Setup

Installing the download

  1. Click Download above — you get the real moveclient-1.5.1.jar directly, no rename step needed.

  2. Install Fabric Loader ≥0.19.5 and Fabric API 0.161.0+26.2 for Minecraft 26.2, if you haven't already.

  3. Drop moveclient-1.5.1.jar into your mods/ folder alongside Fabric API, then launch.

  4. In-game, press ; (semicolon) to open the ClickGUI.

MoveClient v1.5.1 — built for a private/controlled test world. Client-side only, no server code or packet manipulation beyond documented vanilla client actions. Killaura is hard-scoped in code to never target players.
